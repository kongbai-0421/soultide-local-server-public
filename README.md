# Soul Tide Local Server

这是一个独立的本地服务器研究与测试代码仓库。代码用于在使用者自己的受控环境中模拟部分登录、HTTP、SDK、TCP 和数据持久化流程。

本仓库不是官方项目，也不代表、关联或得到游戏开发商、发行商、渠道或任何官方服务器的授权。请先阅读 [DISCLAIMER.md](DISCLAIMER.md)。原创代码以 [MIT License](LICENSE) 发布；该许可不覆盖任何第三方游戏、客户端、协议名称、素材、数据或商标。

## 公开范围

为避免泄露账号和第三方资源，公开仓库不包含：

- APK、签名文件、完整外置资源或 Live2D/音频/图片资源；
- `soultide.db`、玩家数据、人偶师账号、会话、抓包、日志和设备信息；
- 反编译客户端文件和完整 `analysis` 数据集；
- 私有模拟器依赖、密钥、证书和本机路径。

运行完整本地化实例需要使用者自行准备合法来源的运行时配置，并通过环境变量或命令行参数提供路径。公开代码不提供官方账号登录、联网服务或绕过官方服务的功能。

## 开发检查

```powershell
python -m pip install -r .\requirements.txt
python -m py_compile .\storage.py .\login_server.py .\sdk_server.py .\tcp_server.py
```

服务器启动脚本默认使用脚本目录和系统 PATH 中的 Python/ADB；不要把个人路径、账号标识、VPN/代理端口或设备序列号提交到仓库。
